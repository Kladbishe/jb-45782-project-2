About the Crypto Dashboard

This site is my practical project for tracking the cryptocurrency market. It shows the top coins by market cap, lets you mark favorites, and renders a live price chart that updates in real time.

  • Data from CoinCap API v3 (/v3/assets).
  • Live chart refresh ~every 2 seconds based on the current price only (no history).
  • Client-side cache via localStorage with data age control.
  • Favorites list with a max selection limit and quick toggle.
  • Top-100 coins with instant search and responsive layout.
  • Charts drawn on Canvas (e.g., CanvasJS / Chart.js).

Stack: JavaScript/TypeScript, React, Vite, HTML/CSS.
